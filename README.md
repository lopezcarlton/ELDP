# ELDP — Rapid Grant Knowledge Base

> **Knowledge repository for the development of the ELDP Rapid Grant application for _Voces de las Nubes_.**

---

## Purpose

This repository is the **single source of truth** for the preparation of the *Voces de las Nubes* application to the **Rapid Grant** of the **Endangered Languages Documentation Programme (ELDP)**.

Its purpose is to preserve the project's accumulated knowledge, decisions, evidence and working context independently of any individual AI model or chat history.

This repository is **not** the grant application itself.

It is the knowledge base from which the application will be designed and written.

---

## Project status

Current phase:

> **Knowledge consolidation and project design**

The project is still defining the specific pilot that will be submitted to ELDP.

No final proposal has been written.

The objective of this repository is to ensure that when the proposal is written, every statement is supported by previous analysis, documented decisions and official ELDP guidance.

---

## Working philosophy

This repository follows a simple principle:

> **Design first. Write later.**

The proposal should be the consequence of a well-designed project rather than the place where the project is invented.

---

## Scope

This repository documents only the preparation of the **ELDP Rapid Grant**.

It is **not** intended to describe the complete long-term vision of *Voces de las Nubes*.

Long-term institutional goals are included only when they provide necessary context for the Rapid Grant.

## Source hierarchy

When two sources appear to disagree, they should be interpreted according to the following priority:

1. Official ELDP documentation.
2. Explicit project decisions in `02_DECISIONES.md`.
3. Project methodology documents.
4. Evidence collected by the project.
5. Working assumptions.
6. Chat history.

Chat conversations are **never** considered authoritative once their conclusions have been incorporated into this repository.

## Working rules

The repository is updated after each working session.

Every session should answer five questions:

1. What decisions were made?
2. What changed in the project?
3. What remains to be done?
4. What evidence was added?
5. Which documents must be updated?

---

## Design principles

The repository follows several permanent principles:

- One source of truth for every type of information.
- Decisions are never rewritten silently.
- Assumptions are explicitly identified.
- Evidence is separated from interpretation.
- Ideas are not decisions.
- The backlog remains intentionally small.
- The project always has a single active priority.

---

## Current objective

The immediate objective is to design a rigorous, realistic and competitive proposal for the **ELDP Rapid Grant**.

Only after the project has been fully designed will drafting begin.
